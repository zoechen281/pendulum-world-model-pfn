# Oracle MPC 诊断协议

固定 random shooting 规划器，只替换候选动作序列的评分动力学。
learned 使用归档残差 MLP；oracle 使用 Pendulum 的真实状态和仿真动力学。
每条候选从同一真实状态副本出发，不承接上一条候选结束后的状态。

- 规划长度 H∈{5,15,30}，候选数 N∈{20,200}，环境种子为 100、101、102。
- learned/oracle 每次重规划共享候选库前缀，只执行选中序列的首个动作。
- 每回合最多执行 200 步；随机策略每个环境种子执行一回合，总计 39 回合。
- 成功：执行后真实状态连续至少 20 步满足 |wrap(theta)|<0.2 且 |omega|<1。
  中途保持成功与末 20 步稳定分开记录。
- 预测累计回报不折扣，不加入终值函数。

判读：oracle 在有限候选搜索下仍可能失败。H=5 时两种评分动力学均失败，
支持短规划设定不足，不能证明模型误差无影响或唯一因果。
H=15/30 时均成功，仅说明这些开发案例中模型已足以支持相应规划设置。
不同 H 下的搜索维度和覆盖也不同，不能据此断言规划越长越好。
